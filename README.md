# Parkiva

**Smart Parking. Simple Reservations.**

Parkiva is a Public Parking Reservation and Management System currently under development as an academic web development project. The full system is intended to help drivers find participating parking facilities and reserve spaces, while helping operators manage reservations and occupancy.

## Current Status

Development landing page only. Parking reservations, QR verification, and operator management are planned functionality.

## Technology Stack

- React JS
- Vite
- JavaScript and JSX
- CSS with Flexbox
- Git & GitHub

## Development

Install Node.js and npm, then run:

```bash
npm install
npm run dev
```

No environment variables are required.

## Production Build

```bash
npm run build
```

Vite generates the production website in `dist/`. It can be deployed to Vercel or Netlify using `npm run build` as the build command and `dist` as the output directory.

## Branding

Parkiva uses its own visual identity and `public/parkiva.png` as the official project logo. The favicon uses the logo symbol without the wordmark.
